About Project

Project Name

Real-Time Financial Portfolio & Risk Management Database

Project Description

This project demonstrates how a relational database can be used to store investor information, stock details, investment holdings, and price history. It uses SQL queries to calculate portfolio value, profit or loss, allocation, and simple risk indicators.

All stock prices are illustrative sample data. This application does not connect to any live market feed or financial data provider.

Technology Stack

  • Frontend: HTML, CSS, Vanilla JavaScript
  • Backend: Node.js with Express.js
  • Database: MySQL
  • DB Connector: mysql2 (with promise support)
  • Charts: Chart.js

How the Application Works

  1. The browser (HTML + CSS + JavaScript) sends HTTP requests to the backend.
  2. The Express.js backend (Node.js) receives those requests and runs SQL queries.
  3. The MySQL database stores all data and returns results to the backend.
  4. The backend sends JSON responses back to the browser, which displays the data.
